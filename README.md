About

This repository contains the practical programs of Design and Analysis of Algorithms (DAA) implemented using C++.

The programs demonstrate different algorithmic techniques and concepts studied in the DAA course.

Technologies Used
C++
Visual Studio Code
GCC Compiler
Git & GitHub
How to Run

Open the project folder in VS Code and open the terminal.

Compile the program:

g++ DAA_5th_pratical.cpp -o DAA_5th_pratical.exe

Run the program:

.\DAA_5th_pratical.exe

Replace the filename with the practical you want to run.

Purpose

The purpose of these practicals is to understand the implementation, working, and analysis of different algorithms using C++.
